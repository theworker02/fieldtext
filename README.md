# fieldtext

Field filesystem text paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/fieldtext/

## Install / run

```bash
git clone https://github.com/theworker02/fieldtext.git
cd fieldtext
node src/cli.js
node --test
```
